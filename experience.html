Research Experience

CausIDL: Resource Competition-Aware Causal Graph Discovery for Deep Learning Microservices
Sep. 2025 - Jun. 2026
Individual research project · advised by Prof. Zhijun Ding, Tongji University
  • Modeled causality at the individual service-instance level, using resource metrics (GPU/CPU utilization, memory bandwidth, GPU memory) together with performance metrics (request volume, error rate, latency), rather than assuming that all instances of a service type behave alike.
  • Introduced node-level aggregate metrics as shared parents, so that indirect resource competition between instances sharing a physical node becomes an explicit mediation path and is not mistaken for a direct causal edge between instances.
  • Encoded GPU hardware characteristics, container isolation principles and inference service workflows into a forbidden-edge list, shrinking the causal search space by more than 20% and excluding physically invalid directions.
  • Built a semi-automated validation loop that checks learned edges against hardware logic and service workflows; violating edges are added to the forbidden list and the algorithm is re-run, which iteratively improves graph quality.
