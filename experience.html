Research Experience

FSB-Net: Frequency-Spatial Boundary Network for Brain Stroke Lesion Segmentation
Nov. 2025 - Jun. 2026
First author (equal contribution) · advised by Dr. Kai Shu · accepted at IEEE BIBM 2026 (CCF-B)
  • Developed FSB-Net for stroke lesion segmentation in non-contrast CT, using high-frequency information to improve the modelling of unclear lesion boundaries.
  • Built a wavelet-based boundary detection head that applies discrete wavelet transforms to multi-scale encoder features to extract high-frequency boundary representations, with learnable threshold gating to suppress low-amplitude noise.
  • Introduced a frequency-spatial cross-attention module that fuses wavelet boundary representations with spatial decoder features in both directions, using a schedule in which spatial features dominate early and the bidirectional pathway opens once training stabilizes.
  • Defined a spectral boundary loss in the Fourier domain to penalize high-frequency discrepancies between predictions and labels, and validated the design by comparing morphological gradient, Canny and HED-style side outputs against Haar DWT, and bidirectional attention against concatenation, addition, residual gating and unidirectional attention.
CausIDL: Resource Competition-Aware Causal Graph Discovery for Deep Learning Microservices
Sep. 2025 - Jun. 2026
Project lead · advised by Prof. Zhijun Ding and Dr. Binbin Feng
  • Investigated why conventional causal discovery methods struggle on deep learning microservices, especially when several instances compete for shared GPU, CPU and memory resources.
  • Built an instance-level causal discovery framework using GPU, CPU, memory, request, error and latency metrics under dynamic service scaling, rather than assuming that all instances of a service type behave alike.
  • Designed a resource-competition-aware enhancement that introduces node-level aggregate metrics as shared parent nodes, so indirect contention between co-located instances becomes an explicit mediation path instead of a spurious direct edge.
  • Developed a domain-knowledge-guided pruning mechanism that encodes GPU hardware characteristics and inference-service logic as causal priors in a forbidden-edge list, cutting the unnecessary causal search space by more than 20%.
  • Built a semi-automated validation loop that checks learned edges against hardware logic and service workflows; violating edges are added to the forbidden list and the algorithm is re-run, which iteratively improves graph quality.
